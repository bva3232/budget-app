# 월 가계부

카드 사용 내역과 생활비 예산을 기준으로 한 달 지출을 관리하고, 월급에서 저축·주식을 따로 기록하는 웹 앱입니다. 빌드 과정 없이 HTML 파일 하나로 동작하며, 휴대폰 홈 화면에 앱처럼 설치할 수 있습니다(PWA).

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면, 스타일, 로직) |
| `manifest.json` | 홈 화면 설치용 앱 정보 (이름, 아이콘, 색상) |
| `sw.js` | 오프라인에서도 열리게 하는 서비스 워커 |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |

## 기능

- **요약**: 월급 → 생활비 / 저축 / 주식·투자 / 남은 돈 비율 막대, 생활비 예산 대비 사용액, 남은 날 하루 사용 가능액, 저번달 대비 증감, 분류별 지출
- **카드내역**: 지출 직접 입력, 카드사 앱·문자 내역 붙여넣기로 한 번에 가져오기, 사용처 이름으로 분류 자동 추정, 사용처·결제수단 검색 및 분류별 필터, 내역 수정(✎)·삭제
- **저축·주식**: 저축과 투자를 따로 기록, ‘매달’ 항목은 새 달에 자동으로 채워짐
- **체크리스트**: 매달 챙길 일, ‘매달 반복’ 항목은 새 달에 다시 나타남
- **데이터 백업**: 체크리스트 탭 하단에서 전체 데이터를 JSON 파일로 내보내거나, 백업 파일을 불러와 복원

데이터는 브라우저의 `localStorage`에 저장됩니다 (키 앞머리 `budget-app:`). 서버로 보내지 않으며, 기기와 브라우저마다 따로 저장됩니다.

## 로컬에서 실행

서비스 워커는 `file://`로 열면 동작하지 않으니 간단한 서버로 띄우세요.

```bash
npx serve .
# 또는
python3 -m http.server 5173
```

Cursor에서는 이 폴더를 연 뒤 터미널에서 위 명령을 실행하고 표시되는 주소를 브라우저로 여세요.

## 휴대폰에 설치하기

홈 화면 설치는 **https 주소**에서만 됩니다. 무료로 올리는 방법 예시:

1. **Netlify Drop**: https://app.netlify.com/drop 에 이 폴더를 끌어다 놓기
2. **Vercel**: `npx vercel` 실행
3. **GitHub Pages**: 저장소에 올리고 Settings → Pages에서 켜기

올린 주소를 휴대폰에서 열고:
- 아이폰: Safari → 공유 버튼 → ‘홈 화면에 추가’
- 갤럭시: Chrome → ⋮ 메뉴 → ‘앱 설치’ 또는 ‘홈 화면에 추가’

## 수정할 때 참고

- 분류 목록: `index.html`의 `CATS` 배열
- 자동 분류 규칙: `RULES` 배열 (분류명, 사용처 정규식)
- 붙여넣기 파싱: `bulk-go` 클릭 핸들러
- 색상: `:root`의 CSS 변수 (`--live` 생활비, `--save` 저축, `--stock` 투자)
- 앱 파일을 고친 뒤 휴대폰에 바로 반영되지 않으면 `sw.js`의 `CACHE` 이름을 `budget-v2`처럼 바꾸세요.
